# Crop Rotation Planning — mockup

Password-protected pilot mockup of a five-year crop rotation planner for the
Crop Decision Tool (Agricultural Data Economics Lab, University of Saskatchewan).

Open: https://peterjslade.github.io/crop-rotation-planner/

The page is AES-256-GCM encrypted and decrypts in your browser with the password
you were given. Nothing readable is hosted here and nothing is sent to a server.
All numbers in the mockup are illustrative placeholders.
